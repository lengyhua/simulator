# ref-data/ — 定位 XRD 参数的参考数据

用途：存放**人工添加的参考数据**（原程序输出记录、对照表、抄录系数等），
辅助当前项目定案 XRD 计算参数。

## 目录边界

| 目录                                                          | 性质                           | 是否在此管理 |
| ------------------------------------------------------------- | ------------------------------ | ------------ |
| 根目录 `Factor.dat`、`FF.dat`、`Wyckoff`、`WholeSG` 等 | 原程序读取的输入数据源         | 不动，不迁入 |
| `docs/data/*.csv`                                           | `.dat` 的解码 CSV 镜像       | 不动         |
| `references/`                                               | 外部权威源（IUCr、gemmi、ITC） | 不动         |
| `ref-data/`（本目录）                                       | 本项目新增的定位参考数据       | 是           |

## 组织约定

- **按用途分子目录**（如 `single-xrd/`），每个子目录一个主题。
- **一个数据文件 = 一条数据**（一条 single-XRD 输出 / 一组参数）。文件头 `# <编号>
  <晶体> <晶系> <SG>`，编号三位零填充、全目录内单调递增。
- 每个数据文件自含完整信息，独立可读：一段来源说明 + 一张**参数表**（横排，
  **每个参数独占一列**，如 晶体/晶系、a、λ、F′F″、Thermal、L-P、PeakShape、
  q、Occup、B 等，只列该条实际涉及的）+ 原始输出包在 ```text 代码块中
  （保留列对齐，不逐行加 `#`）。
- 后续会逐个参数做对照（B、λ、F′F″ 开关、q …），故**标题不含具体参数值**，
  只到晶体/晶系/SG；参数差异全部写进参数表对应列。
- 新数据加到对应子目录，编号续取当前最大值 +1，并在下方「数据清单」对应
  类型表登记一行（各列随数据扩充，未涉及的留空）。
- 数据文件本身不改写原值；如需注释，加在参数表下方或文件内行注释。

### 控制变量对照怎么做

文件名只保留编号（纯三位），**参数取值一律不进文件名**，全部写在两处：

- 数据文件内的横排**参数表**（自含，独立可读）；
- README「数据清单」里该类型的**矩阵表**（一行一条，参数逐列展开）。

矩阵表本身就是对照矩阵：要对比两条数据时，取两行，**看哪些列不同**即得对照关系
（只 B 列不同 → B 对照；只 L-P 列不同 → Lp 对照；只 λ 列不同 → 波长对照）。
所以**不需要给文件名或表加批次/组列**——同参数数据天然排在相邻列相同的行里，
对照 = 找"仅某一列取值不同、其余列全同"的两行。

## 数据清单

按数据类型各建一张表；每种数据类型的表把该类型涉及的全部参数**逐列展开**，
一行一条数据。未涉及的数据类型新增一张表即可（表内只列该类型实际用到的参数）。

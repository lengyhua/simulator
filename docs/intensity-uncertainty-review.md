## 0. 项目熟悉小结

CalcXRD 是 Delphi 7 闭源 `CalcXRD.exe` 的 Web 重实现（React18+Vite+TS，位于 `web/`）。核心是把"给定晶体结构 → 粉末 XRD 图谱"的计算引擎忠实复刻原程序，并以 GUI 实测（`pywinauto` 驱动原程序）作为验收基线。

已完成的工作（截至本评审）：
- **公式分析（高见远）**：`docs/physics-audit.md` 对 11 个物理模块逐文件审计，结论"全部正确，0 致命/0 显著/3 轻微"。
- **FF.dat 解码（高见远）**：`docs/ff-dat-spec.md` 完全解析 92×104 字节布局、6 组交错 (f′,f″) 列、波长身份、Z=91 误标等。
- **引擎实现与测试**：`structure_factor / intensity / lorentz / gaussian / pipeline / dispersion / wyckoff / cronie` 等模块落地，134 项测试 + Al/NaCl 六峰/九峰 GUI 基线验收通过。
- 物理口径已 GUI 实测锁定：`q=0.10`（σ，非 FWHM）、逐原子 B 默认 1、四复选框默认全开、无全局 B。

**一句话定位**：引擎对 legacy 的**保真度已很高**；强度公式链"正确"结论成立（保真口径）。本评审要补充的，是这套"正确"背后**真正的强度不确定性**——它们不影响 Al/NaCl 交付，但会在新样本/新靶/离子化合物上暴露。

## 1. 关于"正确性"的两层判断（前提）

高见远审计的"正确"= **（a）与 legacy CalcXRD.exe 一致** + **（b）符合标准物理式**。这是"**保真**"口径，不是"**与真实物理一致**"口径。

作为 XRD 专家，我把强度相关结论分成四类，避免把"保真正确"误读为"物理无歧义"：

| 类别 | 含义 | 本项目的例子 |
|---|---|---|
| ✅ 已锁定正确 | 保真 + 标准式，无歧义 | 标准 Lp 形状、`\|F\|²`、多重性含 Friedel、d/2θ、反射枚举完备性、高斯面积守恒 |
| 🟡 保真但有物理近似上限 | 与 legacy 一致，但 legacy 本身做了简化 | 各向同性 B、纯高斯、无吸收/择优取向、单 Kα 线 |
| 🟠 数据/覆盖缺口 | 表本身不全，回退/置灰 | FF.dat 无离子条目、Cr/Fe Kα 无数据、Ce 录入缺陷 |
| 🔴 真正的开放歧义 | legacy 行为未坐实，可能两种都对 | **Kα1/Kα2 是否双线叠加**、"DW 仅作用于 f₀" vs 作用于整体 f |

下面 §2 是核心——**强度参数的不确定性清单**。

## 2. XRD 衍射强度参数的不确定性清单（核心）

> 严重度：🔴 高（影响显著、需主理人拍板）/ 🟠 中（特定场景显著）/ 🟡 低（近似上限、可接受）/ ✅ 已闭环。

### 2.1 热因子 B（Debye–Waller）—— 最隐蔽的强度旋钮 🟠

| 项 | 说明 |
|---|---|
| 当前实现 | 逐原子 B（`.cord` 第 7 字段 / `Atom` 的 `thermalB`），默认 **1 Å²**；DW 仅作用于 f₀（`exp(−Bⱼ·s²)`）；各向同性。 |
| 不确定性来源 | 1) **B=1 是 GUI 拟合占位值，不是物理常数**。真实 B 依赖元素、温度，且一般各向异性（本项目只各向同性）。2) **"DW 仅作用于 f₀" 还是 "作用于整体 f" 无法由参考谱分辨**：`ff-dat-spec §5.5` 实测两者各自重扫 B 都能拟合 Al.xrd（B=1.03 vs 0.99），即**存在残留建模歧义**。3) B 的角度敏感性：`I_high ∝ exp(−2B·s²)`，高角峰对 B 极敏感。 |
| 量级/影响 | Al(400) 的 +2.51% 残差中，B 非最优可能占一部分；任何"非 Al/NaCl"的新样本用 B=1 都是未验证假设。B 改变 0.1 Å² 在高角可移动几个 % 强度。 |
| 受影响场景 | 所有样本（尤其高角弱峰、含轻/重原子混合、低温/高温）。 |
| 功能性缺口 | `SettingsPanel` 只有 Thermal 开关；B 只能在 `AtomTable` 逐原子改，无全局 B 快捷调节，默认值 1 也缺乏 UI 引导。 |
| 建议 | ① 明确文档：B=1 是占位、需按样品给定；② 评估是否加全局 B 快捷滑块；③ 在测试基线保留 B=1.03 与 1.0 两档（残差 0.059% vs 0.195%）。 |

### 2.2 异常散射 F′F″ —— 离子缺失 + 覆盖缺口（对多原子/离子化合物最大）🟠🔴

| 项 | 说明 |
|---|---|
| 当前实现 | `FF.dat` 92 中性元素、**无离子条目**；Cr/Fe Kα 无数据→置灰；Z=91 误标已按 Z 索引修正；Kα1 列精确命中（Δλ=0）。 |
| **离子色散缺失** | `Na1+`/`Cl1-`/`O2-`/`Fe2+`… 全部回退中性（与 `cronie.ts` 同口径）。对**离子化合物**，`F=f_Na−f_Cl` 这类**差项**对 f′ 的微小差异极敏感，而 f₀ 却用了 `factor_data.ts` 的真实离子系数 → **内外不一致**。NaCl 全奇弱峰实测残差：(111) −0.1%、(311) **+5.7%**、(331) **+3.6%**（`pipeline.test.ts` 已锁定为"已知近似上限"）。**这是离子/多物种化合物最大的已知强度不确定性。** |
| **Cr/Fe Kα 覆盖缺口** | 选 Cr/Fe 靶时 f′=f″=0。若用 **Fe 样品配 Fe Kα**（贴近 Fe K 吸收边），异常散射本应极大，忽略它是**大误差**；目前只能"置灰保真"，等于屏蔽了这两种靶的正确强度。 |
| **Ce 录入缺陷** | Z=58 Ce 的 Cu Kα1 `f′=−1.087`（应 ≈−1.8，其 Kα2 条目 −1.818 已是正确趋势，几乎复制了 Z=56 Ba 的 −1.014）。`FF.dat` 原始字节级确认，非解码误差。影响含 Ce 样品（CeO₂ 等）在 Cu Kα 下的色散。 |
| ✅ ~~Kα1/Kα2 双线叠加~~ | ~~引擎只用 Kα1 列，若 legacy 实际叠加 Kα1+Kα2，则漏算高角卫星（Al(400)+2.51% 头号嫌疑）。~~ **已定案（2026-10-16，`ff-dat-spec.md` §7.5）**：Al.xrd 99.94°（Kα2(400) 预测位置）实测 I=18 ≈ 背景，**无 Kα2 独立卫星峰** → legacy 只用 Kα1，引擎取最近列不叠加，与 legacy 一致，**此不确定性已消除**。 |
| 建议 | ~~① 回到 legacy GUI 实测取证"双线 or 单线"~~（已取证，Al.xrd 数据本身足够）；② 离子色散：从 Cromer–Mann/CVIP/XrayDB 补 FF.dat 离子条目的 P2 工作；③ Cr/Fe：置灰（保真）or 现代表补充（偏离保真）需拍板；④ 修 Ce 录入缺陷。 |

### 2.3 峰形 / 展宽 q（σ=0.10°，全局常数）🟡

| 项 | 说明 |
|---|---|
| 当前实现 | 纯高斯，`q=0.10°`（σ，FWHM≈0.2355°）；`q≤0` 落 δ 棒谱。 |
| 不确定性来源 | 真实剖面是 **pseudo-Voigt**（仪器 Lorentzian + 尺寸/应变展宽）。单晶尺寸（Scherrer ∝ 1/(cosθ·size)）与微应变（∝ tanθ）使 FWHM **随 2θ 与样品变化**，而 q 是全局常数。 |
| **关键澄清（很重要）** | 高斯 `1/(q√2π)` 因子对**所有峰相同** → **相对强度比与 q 完全无关**；且单峰面积=intensity（保面积）⇒ **积分强度守恒**。所以 q **不影响相对强度比**，只影响**绝对峰高**与视觉剖面。代价：引擎"List 强度=高斯峰高"强烈依赖 q——若用户拿峰高与实测谱（真 Voigt）比对，会有系统性偏差。 |
| 影响 | 相对峰位/相对强度 ✅；视觉剖面形状与绝对峰高 🟡。 |
| 建议 | 文档明确"List 强度=峰高、对 q 敏感、相对比与 q 无关"；P2 可考虑 θ-依赖的伪 Voigt。 |

### 2.4 Lorentz–偏振因子 Lp —— 偏振假设 🟡

| 项 | 说明 |
|---|---|
| 当前实现 | 标准非偏振束式 `Lp=(1+cos²2θ)/(sin²θ·cosθ)`，θ=2θ/2。 |
| 不确定性来源 | 真实实验室衍射仪带**晶体单色器**（部分偏振，η≈0.95）。单色化束的粉末 Lp 偏振项应为 `(1+ηcos²2θ)` 等变体；η<1 时高角强度比有**数 % 偏差**。 |
| 影响 | 与 legacy 一致（也匹配 GUI 基线），故"保真正确"；但与**现代实测谱**比会在高角有小幅系统性差。 |
| 建议 | 作为已知保真上限记录即可；若要贴合现代仪器，加 η 偏振因子（P1 可选）。 |

### 2.5 绝对强度 & 缺失的物理项 —— 强度模型的适用范围 🟠

引擎输出**相对积分强度（归一化到 100）**，模型隐含假设：**运动学、理想粉晶（随机取向）、无吸收**。它**未包含**：

- **吸收校正**（μ、样品几何：平板/毛细管/旋转台显著影响低角强度）；
- **择优取向 / texture**（真实粉晶强度失配的**头号原因**——如片状晶体 (00l) 异常增强）；
- **初级/次级消光**；
- **各向异性原子位移**（仅各向同性 B）；
- **绝对标度**（K=1，仅相对）。

> 范围声明：本工具是"**运动学理想粉晶峰位与相对强度模拟器**"，适合峰指认、相对强度粗略比对；**不适合定量 Rietveld / 绝对强度**。用户（及 UI 文案）应明确此边界。NaCl (311)/(331) 等弱峰的偏差，部分是该边界内的固有近似，而非纯代码误差。

### 2.6 多重性 & Friedel 对（已确认正确，但依赖一个假设）✅

`F(−hkl)=F(hkl)*` ⇒ `|F(−hkl)|²=|F(hkl)|²` 对任意晶体（含反常散射）恒成立，故 `mult × |F|²` 含 Friedel 对正确。成立条件同 §2.5（运动学/非偏振/理想粉晶平均）。**无独立不确定性**，但它是 §2.5 同一条假设链的一环。

### 2.7 数据表精度 / 量化 🟡

- `FF.dat` 数值量化到 **3 位小数**（~0.001 精度，人工抄表常数）；`Factor.dat` 系数有限精度。
- 对强峰相对强度可忽略；对**异常差项**（NaCl 弱峰）的 0.001 量化会叠加进 ~几个 % 的不确定性（与 §2.2 离子缺失叠加）。

## 5. 结论

1. **保真口径下"强度公式正确"成立**：标准 Lp、`|F|²`、多重性含 Friedel、d/2θ、高斯面积守恒、反射枚举完备性均已逐项验证，Al/NaCl GUI 基线验收通过。
2. **真正的强度不确定性来自两条线**：
   - (a) **模型简化**——各向同性 B、纯高斯、无吸收/择优取向（§2.1/2.3/2.5）；
   - (b) **数据缺口**——离子色散缺失（离子化合物最大误差源）、Cr/Fe 覆盖、Ce 缺陷（§2.2）。
   - ~~(c) Kα1/Kα2 是否双线叠加~~ → **已定案（2026-10-16）**：legacy 只用 Kα1，
     证据见 `ff-dat-spec.md` §7.5（Al.xrd 99.94° 无 Kα2 卫星峰），不再构成不确定性。
3. **不阻塞当前交付**：4 个样本（Al/NaCl/BaTiO₃/Po）不含 Ce、非 Cr/Fe 靶、离子化合物已锁定残差上限；但**任何新样本**（尤其含 Ce、离子晶体、或用 Cr/Fe 靶）都需先解决对应不确定性。
4. **文档健康度问题**：`CLAUDE.md` 对 FF.dat 尺寸/解码/异常表来源有事实性错误，应优先修订以指导后续贡献者。

> **更正（2026-10-19，定案 6 闭合形式定案）**：初稿"s²≠1/(4d²)、B_eff

**方法**：capstone 32-bit 线性反汇编 `CalcXRD.exe` DW 分支
（0x47c897–0x47c8b4）+ 前置 s² 块（0x47c6e4–0x47c706）：

```asm
; s² 计算段（0x47c6e4–0x47c706）
fld  2.0f@0x47ca7c          ; load constant 2.0
fmul [d_hkl]@0x27228+i*8   ; 2d
fld  2.0f@0x47ca7c
fmul [d_hkl]

fld  [0x440+8·edi]         ; B（逐原子记录偏移 0x440）

fmul [0x420+8·edi]         ; × occ
```

   （相对衰减 = exp(−2B(N−3)/(4a²))，"2" 来自 f→|F|² 平方），

## 定案 6（2026-10-18 初稿 → 2026-10-19 闭合形式定案）：DW = `e^(−B·N/(4a²))`，111 归一后 `I(N)/I(3) = e^(−B·(N−3)/(2a²))`

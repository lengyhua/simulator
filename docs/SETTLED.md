## 1. 几何与角度

### 1.1 2θ 的量化口径（最关键的 legacy 怪癖）

| 项 | 结论 |
|---|---|
| **结论** | `2θ_report = Round(Single(Round(2θ·1000)/1000) · 100)/100` —— 先量化到**毫度**、以 **Single(32-bit)** 存储，报表再取 **2 位小数** |
| **依据** | 字节级实读 VA 0x47875c–0x4787b5：`fld λ; fdiv 2.0; fdiv d` → `call 0x427170`（ArcSin = `ArcTan2(x, √(1−x²))`，fsqrt@0x42718f / fpatan@0x4271b9）→ `fmul 2.0; fld π; fdivp; fmul 180.0; fmul 1000.0` → `call 0x402a10`（Round→Int64，`fistp qword`）→ `fild; fdiv 1000.0; fstp dword [ebx+esi*4+0x3e92c]` |
| **连带口径（同样关键）** | 报表 **d 由报表角反算**：`d = λ/(2·sin(2θ_report/2))`，不是晶胞精确值 a/√N；**Lp、\|F\|²·mult、高斯峰中心全部在报表角上求值**。因高斯核在中心取 1，0.01° 网格最大值即等于报表 I |
| 代码 | `pipeline.ts` `legacyPowderReportAngle()`（`Math.fround` = legacy 的 Single 存储） |
| 状态 | ✅ 已实施。Al 六峰逐值命中 `Al.RTF`；网格 38.63 = 152557 对齐 `samples/Al.xrd` |
| ⚠ 曾误判 | 「2θ 直接用精确 Bragg 角」——导致 powder d / I 对不齐（2026-10-19 修正） |

## 3. 结构因子

### 3.1 色散 F′/F″（实公式）

| 项 | 结论 |
|---|---|
| **结论** | 实公式 = `f₀ + f′ + 0.5·f″²/(f₀+f″)` —— **分母是 f₀+f″，不是 help 公式 (5) 的字面 f₀+F′** |
| **依据** | 双路径同构：粉末 0x47894a–0x47899a + single 0x47c7f2–0x47c842；FDIVP@0x478992 / 0x47c83a；0.5f@0x478d18 / 0x47ca84。字节级补证：0x47c833 `DC 84 C3 60 39 00` FMUL 确认分母槽为 f″ 而非 f′ |
| **RTF 报表同式** | 「Fo after F1 & F2」列与计算管线**用同一式**（`001-Al.rtf` 三行对照残差 4.3e-8 = 报表 %.9f 截断） |
| 代码 | `structure_factor.ts` legacy 分支 |
| ⚠ 曾误判 | §6.3「报表故意用 help 式（分母 f₀+F′）」——作废（2026-10-19 §8.19） |

### 3.2 Debye–Waller 温度因子（M3 形式）

| 项 | 结论 |
|---|---|
| **结论** | DW 乘在**整个 f_eff 之后**（含色散修正项）：`f_contrib = D·(f₀+f′+0.5f″²/(f₀+f″))·occ`，全程**实数标量**、无复数运算 |
| **依据** | single 0x47c885–0x47c8b4（`FLD B; FCHS; FMUL s²; CALL exp(0x4029c4); FMUL f_eff; FMUL occ`）+ 粉末同构；单路径 0x47c8a9 `FMUL [ESP+0x10]`×D×occ 定稿 |
| **与 IT Vol. C 的差异** | IT 规范是「DW 只作用 f₀」；legacy 是 M3（含色散项）。**保真优先 → 复刻 legacy** |
| 代码 | `structure_factor.ts`；single 表**钉死** `dispersionForm:'legacy'` |
| 状态 | ✅ Al B 扫描 35 点 ≤0.006%，闭合形式 0.000% |
| ⚠ 曾误判 | 「DW 作用 (f₀+f′) 整体、f″ 不进 DW」——与字节迹差 ~0.09%，以字节迹为准（M3） |

### 3.3 复数式 vs 标量式

| 项 | 结论 |
|---|---|
| **single 表** | 钉死 **legacy 标量式 M3**，逐值复刻原程序 |
| **powder 管线** | 用**复数式** `fⱼ=(f₀·e^{−Bⱼs²}+f′)+i·f″`（DW 只作用 f₀，IT Vol. C 物理正确）；多原子结构必须用复数式（NaCl 弱峰标量 vs 复数差可达 2–3%） |
| 依据 | 32 开关组合 Lp/Th/Fd/PS × legacy/complex 逐值扫描：命中原程序的是 `Lp开 Th开 Fd开 form=legacy` |
| 代码 | `single_xrd.ts` / `structure_factor.ts` 独立 `sfOpts` |

### 3.4 相位（岩盐基底）

| 项 | 结论 |
|---|---|

### 3.5 FF.dat 列选择与错配

| 项 | 结论 |
|---|---|
| **FeKa1/FeKa → Co 列** | 选 FeKa1/FeKa 时，λ 用 Fe 值（1.93604/1.93736）而色散实读 **Co Kα1/Co Kα2 列**（latent 错配） |

### 5.1 powder List / RTF 报表

| 项 | 结论 |
|---|---|
| **按 d 分组** | 2θ 相同的反射**共用一行**，hkl 列列全部成员，`I` = 各族之和，I/Io 在**行级**重新归一化（最强行 = 1000） |
| **依据** | `NaCl.RTF` 末行 32 个 hkl：`{333}`(mult 8) 与 `{511}`(mult 24) 同属 N=27 → d 相同 → 合并为 I=9325、Io=9‰、mult=32（分账 2331+6994=9325、2+7=9） |

# single XRD 表强度公式审计（2026-10-17）

> 触发：用户报告「web 添加的 Single XRD 计算结果与原程序差别很大」
> （原程序 Al / Cubic 225(Fm-3m) / a=4.0339 / λ=CuKa1 1.54056，
> F′F″、Thermal、L-P、PeakShape 全开）。
> 2026-10-17 晚：**全部公式已定案并改入代码**（见 §8），以下为历史调研
> 记录 + 定案结论。

## 1. 结论摘要

原程序 single XRD 表**每行**强度为：

```
I_hkl = K · Lp(2θ_hkl) · |F_hkl|²        ← 无 multiplicity（轨道多重度不参与）
|F_hkl|² = (Σ_j f_eff,j)²                 ← 所有原子同相相加（不计基底位置相位，见 §5）
f_eff,j = √( ((f0,j + f′,j)·e^(−B_j·s²))² + f″,j² )   ← 实数原子因子（见 §4）
```

整表归一到 max = 100000。`s = sinθ/λ = 1/(2d)`，`Lp = (1+cos²2θ)/(sin²θ·cosθ)`，
`B_j` 为 .cord 第 7 字段（逐原子）。

**2026-10-17 定案补充（§8）**：
- 偶次晶面（h+k+l 偶）：完整复数模 `Re²+Im²`，Re=`8(f_Na+f_Cl+f′_Na+f′_Cl)`，
  Im=`8(f″_Na+f″_Cl)`（Fd 开时）
- 奇次晶面（h+k+l 奇）：`|F|² = [8(f_Na−f_Cl+f′_Na−f′_Cl)]²`，**f″ 不进奇次族**
  （`structure_factor.ts` `rockSaltOddReal` 选项，Fd 关时自动无影响）
- 归一基数 = 全扫描范围 `[rangeMin, rangeMax]` 内 Lp·|F|² 的全局最大值
  （含 legacy 表未显示的弱峰；NaCl 为 (200) 族，Al 为 (111) 族）

## 3. 「无 mult」的物理意义

原程序 single XRD 表逐行列出 Laue+Friedel 轨道中的**每一个** (h,k,l) 像点，
每行给的是**单个反射**的强度（Lp·|F|²），不是轨道合计。这与「单晶衍射数据」
的语义一致（粉末法才需要乘多重度）。对照证据：同一程序的**粉末**曲线
（`samples/Al.xrd`，GUI 验收基准）六峰 I/I₀ = 1000/470/266/283/80/37，
与 `mult·Lp·|F|²` 吻合——即粉末模块含 mult、single 表不含，两个模块口径不同。

## 4. 原子因子口径：实数 f_eff 与 DW 作用对象

原程序 Search Factor 报表（`ref-temp/CuKa1 Na1+.rtf`）直接给出组合方式：

```
Element Name :  Na1+ ;  Target : CuKa1  1.54056
DeltaF1 =  0.136;   DeltaF2= 0.124
 2theta   sin(theta)/lamda    Fo          Fo after F1 & F2
 51.00    0.27945104          7.203135728 7.340184979
```

数值核验：`(f0+f′) + f″²/(2(f0+f′))` = 7.339136 + 0.015376/14.678272 =
7.3401835 ≈ 报表值 7.3401850——即 help 公式 (5) 的**二阶 Taylor**：
`f_eff = √((f₀+f′)² + f″²)`（复数模长），程序以实数形式使用。

强度公式中的热因子位置由 Al 导出反解定案：对每个反射反解隐含 B
（形式 `((f0+f′)e^(−Bs²))²+f″²`）得 **B = 1.0025~1.0031 全反射一致**
（.cord B=1，残差为导出值整数量化 ±0.005%）；若 DW 只作用 f₀
（`(f0·dw+f′)²+f″²`）则隐含 B 系统性漂移、最大偏差 1.87%。
故定案：**DW 作用于 (f₀+f′) 整体，f″ 不进 DW**。

web 现行 `structure_factor.ts` 用 `(f0·e^(−Bs²)+f′) + i·f″` 复数式：
- f₀+f′ 与 DW 的先后差异 → Al 上 ≤1.87%（轻原子小，重原子大 f′ 时更大）；
- 复数模长与实数 f_eff 在强度上等价（|F|² 相同），此项无差异。

## 5. 基底位置相位：single 表不计（legacy 怪癖）

`ref-temp/single-xrd/NaCl-225`（岩盐，Na@4a、Cl@4b）中 **111 族最强
（100000）**、200 为 65638。按正确岩盐结构因子，111 应为
`4(f_Na−f_Cl)` 弱峰（预测 111/200 ≈ 0.07~0.15），绝无可能最强。
`NaCl-75`（同一结构按 P4 描述）导出与 NaCl-225 **逐值一致**，
同样 111 最强 → 排除空间群表错位，确认是 single 表模块本身的行为。

可拟合模型：`Lp·(f_Na+f_Cl)²`（所有原子同相、不计 e^{2πi(hx+ky+lz)}），
即原程序 single 表的 |F|² = (Σ_j f_eff,j)²。
该模型对 NaCl-225 最大残差 19.7%（见 §6），结构定性（111 最强、
无混合指数消光）完全复现。

对照：**粉末**模块对 NaCl 的九峰基准（1000 归一到 200=1000，
111 仅 91）符合正确岩盐物理——相位只在 single 表模块被忽略。

### 8.2 定案公式

**偶次晶面（h+k+l 偶）**：

```
|F|²_even = Re² + Im²
Re = 8·(f_Na·e^(−B_Na·s²) + f_Cl·e^(−B_Cl·s²) + f′_Na + f′_Cl)
Im = 8·(f″_Na + f″_Cl)   [仅 Fd 开]
I = Lp(2θ)·|F|²_even / base × 100000
```

**奇次晶面（h+k+l 奇）**：

```
|F|²_odd = [8·(f_Na·e^(−B_Na·s²) − f_Cl·e^(−B_Cl·s²) + f′_Na − f′_Cl)]²
I = Lp(2θ)·|F|²_odd / base × 100000
   （f″ 不进奇次族；Fd 关时 f′ 亦不进）
```

**归一基数** `base` = 全扫描范围 `[rangeMin, rangeMax]` 内
`Lp(2θ)·|F|²` 的全局最大值（含未显示弱峰）：
- NaCl 恒为 (200) 族 2θ≈31.82°
- Al 恒为 (111) 族 2θ≈38.63°

**实现位置**：
- `structure_factor.ts`：新增 `SFOptions.rockSaltOddReal` 选项；
  当 `(h+k+l) % 2 !== 0` 且 `rockSaltOddReal=true` 时，`im=0`（丢 f″）
- `single_xrd.ts`：`sfOpts.rockSaltOddReal = true`（默认开启，匹配 legacy）
